- API-page fingerprint/WebAuthn/PIN calls send the authenticated bearer session.
- Developer workspace automatically discovers GitHub repositories after login. GitHub OAuth now requests repo and read:org scopes; repository listing includes all visibility and collaboration affiliations and paginates up to 1,000 results.

- API & Agents has a Back to workspace action in both locked and unlocked states.
