Privacy Policy

Last updated: October 27, 2026

Pothub helps inspect repository and deployment issues and prepare code changes. Review and customize this starter policy with your business contact details before public release.

Information processed

  • GitHub profile details used to identify your account.
  • Repository metadata, selected source files and deployment logs you ask us to inspect.
  • Credit purchases, usage records and task metadata needed for billing.
  • Encrypted card fields passed to Flutterwave for payment processing. Pothub is designed not to retain raw card details, CVV, PIN or OTP.
  • Settings and history stored in browser or app IndexedDB.

Code and logs

Source code is fetched from GitHub when needed; the app is designed not to retain a permanent full repository copy. Relevant code and redacted logs may be sent to the configured AI provider. Automated redaction is imperfect; do not submit secrets, private keys, customer data or information you are not authorized to share.

Local storage and backups

Project history and preferences are stored in IndexedDB. Optional Drive backup sends selected backup data to the Drive file you configure. The Drive access token is held in memory only. The local Vercel token is excluded from exported backups.

Service providers

Depending on deployment configuration, Pothub uses GitHub, Vercel, Google Gemini, Firebase Firestore and Flutterwave. Each provider processes data under its own terms. Accurately list the providers actually used before launch.

Retention and deletion

Remove local data by clearing the app's stored site data. Server-side billing and security records may be retained for legal, accounting and operational needs. Add a real account-deletion and contact process before production release.

Security

Server credentials must remain server-side. Review and test changes before merging. Do not use Pothub as a substitute for backups, access control or code review.
